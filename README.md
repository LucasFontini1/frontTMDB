# Frontend TMDB

Projeto frontend relacionado ao TMDB, desenvolvido com Vue 3, Axios e Vue Router.

## Tecnologias

- `axios`
- `pinia`
- `vue`
- `vue-loading-overlay`
- `vue-router`

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar uma versão de produção: `npm run build`.
